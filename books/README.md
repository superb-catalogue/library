# books

One folder per book, named after its Standard Ebooks page (for instance
`bram-stoker_dracula`). Each folder holds two files:

- **`book.json`** — the text, in the book's own stated reading order, as
  chapters made of blocks. Each block keeps whatever type the source itself
  marked it with (a paragraph, a letter, a diary entry, a stanza), so a
  letter in a novel stays recognisably a letter rather than being flattened
  into a plain paragraph.
- **`provenance.json`** — where the book came from, on what terms, and how to
  check that for yourself. It always cites the book's own public page and its
  upstream sources — never a file on someone's hard drive that only they
  could open.

`../books/INDEX.json` is the machine-readable list of everything in here, one
row per book; `../LIBRARY.md` is the human-readable shelf generated from it.
Both are generated by `../scripts/ingest.py` — never edited by hand.

See `HOW-THE-FIRST-BOOK-WENT.md` for the choices that shaped this format, made
by taking one book through by hand before any of it was scripted.
